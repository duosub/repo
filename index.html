🎬 DuoSuob Desktop

DuoSuob Desktop is a modern Open Source application for Linux (Debian/KDE) designed to automatically create dual subtitles. It is the perfect companion for learning foreign languages by watching movies and TV shows.

🚀 Key Features

  • Smart Merging: Combine two different subtitle files into one bilingual file.
  • Auto-Translation: Built-in support for Google, Bing, and Yandex translation engines.
  • Format Support: Full compatibility with SRT, ASS, SSA, and more via pysubs2.
  • Style Customization: Choose fonts, colors, and screen positions (top/bottom) for each language.
  • Standalone: All dependencies are bundled inside; the app works immediately after installation.

📦 Installation (Debian / KDE / Ubuntu)

Open your terminal and run the following commands to add the repository and install the app:

# Add the repository
echo "deb [trusted=yes] https://duosub.github.io/repo/ ./" | sudo tee /etc/apt/sources.list.d/duosub.list

# Update and Install
sudo apt update
sudo apt install duosub-desktop

📖 How to Use

  1. Launch the app from your Application Menu (Multimedia or Utilities section).
  2. Click "Open File" and select your original subtitle file.
  3. Select the target language and translation engine.
  4. Click "Create Dual Subtitles". The app will generate a new file where the translation is placed under the original text.
