# DuoSuob Desktop 🎬

Professional tool for creating dual subtitles with ease.

## 🚀 Installation

To install DuoSuob on Debian-based systems (Debian, Ubuntu, KDE Neon), run the following commands:

```bash
# 1. Add repository
echo "deb [trusted=yes] [https://duosub.github.io/repo/](https://duosub.github.io/repo/) ./" | sudo tee /etc/apt/sources.list.d/duosub.list

# 2. Update and Install
sudo apt update
sudo apt install duosub-desktop
